# UX 시나리오 — 여정 검증 문서

> QA.md가 "기능이 도는가"를 본다면, 이 문서는 **"여정이 끊기지 않는가"**를 본다.
> 각 단계의 상태: ✅ 동작 / 🔧 M7에서 해결 / 📋 백로그. 새 기능을 넣을 때 해당 여정에 단계를 추가하고 끊김을 확인할 것.

## S1. 첫 설치 → 첫 등록 (등록 10초)

1. 앱 첫 실행 → 빈 홈 + "오른쪽 아래 카메라 버튼으로 첫 물건을 등록해 보세요" ✅
2. FAB 📷 → 카메라 권한 요청 (거부 시 행동 안내 + 갤러리 폴백) ✅
3. 라벨 촬영 → 폼 자동 오픈, 기한 자동 인식 (각인 오독 복원 포함) ✅
4. 기한·상표가 다른 면이면 [＋ 다른 면] 추가 촬영 → 스트립에 나란히 표시, 인식 병합 ✅
5. 품목명 입력(유일한 필수) → 저장 → "저장됨 · D-N [하나 더 찍기]" ✅
6. 품목명·브랜드 자동 채움 — 📋 Gemini 크레딧 재개 시 활성 (코드 연결 완료)

## S2. 아침 알림 → 임박 품목 처리

1. 매일 설정 시각에 묶음 알림 1건 ("내일 만료 1건 · 일주일 내 2건 — …") ✅
2. 알림 탭 → 홈 임박(D-30) 필터로 진입 ✅
3. 임박 품목 확인 → 만료 품목 [처리] → 폐기/아직 사용/+30일 연장 ✅
4. 데이터가 바뀌면 다음 1회 알림 자동 재예약 (중복 예약 방지 직렬화) ✅

## S3. 소진 → 3개월 뒤 재구매 (리텐션 핵심)

1. 다 쓴 샴푸 → 상세 [소진했어요] → 아카이브 이동 ✅
2. 재구매 후 아카이브 → [다시 샀어요] → 기한만 입력 → 홈 재등록 ✅
3. 아카이브 행 탭 → 이력 상세 보기 — 🔧 M7-3 (현재 무동작)
4. "재등록됨 ✓" 표시 — 세션 한정 📋 (영속화는 데이터 모델 추가 필요해 백로그)

## S4. 잘못 등록한 품목 복구 (실수 탈출구)

1. 오타·중복·테스트 품목 발견 → 상세 진입 ✅
2. 이름/브랜드/위치/메모/카테고리 수정 — 🔧 M7-2 (현재 유통기한만 수정 가능)
3. 아예 잘못 등록 → 상세 ⋯ → 완전 삭제 (확인 시트, 썸네일 파일 정리) — 🔧 M7-2
4. 아카이브 이력 정리 → 행 길게 누르기 → 삭제 — 🔧 M7-3
   - 원칙: **보존이 기본** — 삭제 버튼은 노출하지 않고 의도적 제스처 뒤에만 (재구매 유도 동선 보호)

## S5. 개봉 실수 → 되돌리기

1. 홈에서 [개봉] 원탭 실수 → 만료일이 PAO 기준으로 당겨짐 ✅(동작 자체)
2. 토스트의 [실행취소] 원탭 복구 — 🔧 M7-2
3. 나중에 발견 → 상세 개봉일 행 탭 → 날짜 수정 또는 비워서 미개봉 복귀 — 🔧 M7-2

## S6. 기한 표기 없는 화장품 (부분 성공)

1. 제조번호만 있는 선크림 촬영 → 기한 인식 실패 = 같은 폼, 에러 팝업 없음 ✅
2. 카테고리 선택 → "선크림 기본값: 개봉 후 12개월 [적용]" 배너 ✅
3. 카테고리 몰라도 라벨 12M 심볼 인식 → "라벨 표기: 개봉 후 12개월 [적용]" ✅
4. [적용] → 오늘 개봉 + PAO로 만료 계산 ✅

## S7. 월말 욕실 정리 (위치 기반)

1. 홈 📍욕실 칩 → 욕실 물건만 필터 ✅
2. 등록 때 위치 칩에서 원탭 선택 — 기존에 만든 위치('화장대' 등)가 다음 등록에도 표시 — 🔧 M7-3 (현재 고정 3종 + 그 자리 추가분만)
3. 폼 작성 중 실수로 ✕/뒤로가기 → 입력 유실 확인 — 🔧 M7-3
4. 커스텀 카테고리 삭제 시 확인 시트 (품목 '기타' 이동 안내) — 🔧 M7-3
