# 007. 유통기한 인라인 수정을 자유 형식 텍스트 입력으로

- **맥락**: 목업의 `input[type=date]`에 해당하는 RN 네이티브 date picker(`@react-native-community/datetimepicker`)는 네이티브 모듈이라 dev build 재빌드(APK 재설치)를 유발한다.
- **결정**: 바텀시트 + TextInput으로 받고 도메인 `parseDates`를 재사용해 `2027.03.15`·`2027-03`·`20270315` 등 라벨 표기 형식을 전부 수용. 빈 입력은 기한 미설정.
- **근거**: 수정은 저빈도 동작이라 타이핑 마찰 허용 범위, 파서 재사용으로 추가 코드 최소. M3 재빌드 시점에 네이티브 피커 도입 재검토.
