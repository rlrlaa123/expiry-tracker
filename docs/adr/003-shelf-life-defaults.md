# 003. builtin 카테고리 보존기간 기본값 + '기타' 시드

- **맥락**: DEV-GUIDE M1은 "builtin 6종 시드 + 보존기간"을 요구하나 보존기간 수치는 미명시. 또 SPEC §7-1의 폴백 규칙(AI 매칭 실패·커스텀 삭제 → '기타')은 '기타' 카테고리의 상시 존재를 전제.
- **결정**: 보존기간(MFG 기준): 화장품류(선크림/립/마스카라/연고) 36개월, 안약 24개월, 조미료 24개월. '기타'를 7번째 builtin(PAO·보존기간 null)으로 시드.
- **근거**: 화장품 미개봉 유통 관례 3년. 설정 화면에서 편집 가능하므로 초기값은 보수적으로. SPEC §2 주석대로 출시 전 전체 재검토 대상.
