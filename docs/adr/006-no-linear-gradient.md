# 006. 목업 그라데이션을 단색으로 대체

- **맥락**: 목업의 썸네일 배경·상세 만료 카드가 CSS gradient를 쓰지만, RN에서 gradient는 `expo-linear-gradient`(네이티브 모듈)가 필요해 dev build 재빌드를 유발한다.
- **결정**: gradient의 중간 톤 단색으로 대체 (썸네일 `#E7EFE4`, 만료 카드는 상태별 진한 단색). 재빌드가 어차피 필요한 M3(카메라 모듈) 시점에 도입 여부 재검토.
- **근거**: 색은 정보 전달(상태 구분)이 본질이고 단색으로도 위계가 유지됨. 사용자 APK 재설치 마찰 > 시각적 미세 차이.
