# 010. 폼 내 "다른 면 찍기" — 추가 촬영 인식 병합

- **맥락**: 실제 제품은 기한 표기와 상표/브랜드가 다른 면에 인쇄된 경우가 많아 사진 한 장으로 전체 인식이 어렵다 (사용자 QA 피드백, 2026-06-12).
- **결정**: 폼 썸네일 옆 "＋ 다른 면 찍기"로 `launchCameraAsync` 추가 촬영 → 인식 결과를 병합(기존 값 우선, 빈 필드만 보강, 날짜는 합집합 재채택). 저장 데이터는 그대로 사진 1장(첫 촬영) — 데이터 모델 변경 없음.
- **근거**: "사진 한 장으로 등록" 정체성과 등록 10초 원칙 유지(추가 촬영은 선택), Out of Scope인 '일괄 연속 촬영'(여러 품목)과 구분되는 한 품목 보강 동작.
